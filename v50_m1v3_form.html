フォーメーションの係数

1着 = 点の1位・2着 = 点の2位（同じ点は馬番の小さい順。点は上で選んだ係数のもので、全券種で同じ1着・2着。能力表の M1順位は M1 v3 正式なので、「回収率最大化 単勝向け L2=0.0001」の1着・2着は M1順位の1位・2位と違うことがある）・3着 = 市場人気1〜5位のうち1着・2着の馬でない馬。単勝は1着の馬、複勝は1着・2着・3着の馬それぞれ、枠連・枠単は1着と2着の馬の枠、馬連・馬単は1着-2着、ワイドは1着-2着・1着-3着・2着-3着、三連複・三連単は 1着-2着-3着。

回収率最大化 単勝向け L2=0.0001 の係数は、第1群で答えを知って作った過学習の係数です（第1群の全券種の合計 99.6%）。第2群では全券種の合計 55.9% [45.7, 66.5]、どの券種も区間の下限が 100% を超えませんでした（記録148）。人気は締切前の oddsJS の値で、研究で使った確定人気ではありません。買い方の根拠にしないでください。

このページについて

能力表: M1 v3 v1（44列。正式の係数 6676e5ff…）。M1順位は M1合計点の順位。市場人気・単勝オッズは、出走表と一緒に読んだ oddsJS の値（有効な馬の単勝オッズの低い順）。M1合計点・能力・加減・格と対戦は、レースの平均を0にした値（M1合計点 = 能力 + 加減 + 格と対戦）。勝率は M1合計点のソフトマックスで、市場と比べる前の目安。初出走の馬が混ざるレースでは勝率とフォーメーションを出さない。全頭が初出走のレースは計算しない。oddsJS で有効でない馬（取消・除外など）は除いて計算する。

  • 能力: 馬そのものの力の点（M1 v2 の A層と D層）。近走の着順・着差・先行力・追い上げ・上がり、前走1着、前5走の走の数・中止・取消除外・能試、直前の欄が普通でないか（A層）と、移籍元（中央・中央未勝利・他地区）と移籍後何走目か（D層）。
  • 加減: 今回の条件による上げ下げ（B層・C層・E層）。前走からの距離の延長・短縮と、走ったことのある距離から離れているか（B層）、前走からの間隔と叩き2走目（C層）、年齢・性別・斤量の差・減量（E層）。
  • 格と対戦: 格R1 と 対戦H1 の4列（値と、記録が無い印）による点。
  • 格R1: 前5走のうち南関東の普通の走（頭数2以上）の格の番号（OP=0、A1=1〜C3=8。題名から読む）の重み付き平均（重み 0.7）。小さいほど格が上。南関東の普通の走に格の番号が無い馬は「記録なし」。
  • 対戦H1: 前5走で今回一緒に走る馬と同じレースに出たときの（先着 − 先着された）÷ 対戦の回数。−1〜+1 で、+1 は今回の相手に毎回先着。今回の相手と走ったことが無い馬は「対戦なし」。
  • 能力表（回収率最大化 単勝向け L2=0.0001）: 同じ44列に、第1群の単勝の回収率を上げるように作った係数を掛けた点。順位はこの点の順位で、フォーメーションの1着・2着に使う。能力・加減・格と対戦は M1 v3 と同じ列の分け方の小計。一部の列（斤量の差など）の重みが極端に大きく、能力の物差しではない。勝率は出さない。プラス要因・マイナス要因はレースの平均との差の大きい列。
  • 網掛け: M1順位〜対戦H1 の列ごとに、良い値ほど赤、悪い値ほど青（M1順位・市場人気・単勝オッズ・格R1 は小さいほど良い、ほかは大きいほど良い）。色の濃さは値の大きさではなく列の中の順位で決める（いちばん良い馬がいちばん赤、まん中の順位が白、いちばん悪い馬がいちばん青。同じ値は同じ色）。「記録なし」「対戦なし」は網掛けしない。

表の見出しを押すと並べ替えます（もう一度押すと逆順。並べ替えた列に ▲▼）。馬番・馬名は横にスクロールしても残ります。フォーメーション表の3着は馬番の小さい順。
